# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.3.x | Yes |
| 1.2.x | Yes |
| Earlier releases | No |

## Reporting a vulnerability

Do **not** open a public issue for a suspected vulnerability that could expose
server owners, player data, credentials or an exploit path. Use GitHub's
[private security advisory form](https://github.com/leminhhuy113/fivem-pro/security/advisories/new)
and include:

- affected file and version;
- minimal reproduction with secrets, IPs and player data removed;
- impact and prerequisites; and
- a safe proposed mitigation if one is known.

We will acknowledge a report within 7 days, assess it privately, coordinate a
fix and credit reporters only with their permission. This repository teaches
defensive patterns; do not submit weaponized exploit code or instructions for
abusing third-party servers.
